# API RPG BAY v1

Base `/api`, JSON UTF-8. Erros `{error:{code,message}}`. Identificadores UUID exceto usuário OIDC (string opaca). Datas UTC ISO 8601; preços em centavos inteiros. Texto editorial/social é texto simples, nunca HTML confiável. Paginação `limit=40&offset=0`, máximo 100 nos endpoints paginados.

## Identidade e transporte

Produção usa OIDC Authorization Code + PKCE, cookie opaco `rpgbay_session` HttpOnly Secure SameSite=Lax de 12h ou Bearer JWT com assinatura, issuer, audience, expiração e algoritmo permitido. Cada mutação cookie exige Origin igual WEB_ORIGIN. Sessões persistem somente hash SHA-256. Logout revoga a sessão local; não promete revogar a sessão corporativa. MFA e reautenticação financeira ainda dependem de integração adicional.

Desenvolvimento exige simultaneamente `NODE_ENV=development`, `DEV_AUTH_ENABLED=true`, header `x-dev-user: dev-user`. Sem fallback em produção. `db:seed` recusa outro ambiente. Nenhuma conta demo ganha administrador. `GET /api/health` e catálogo são públicos. Auth e webhooks têm suas próprias verificações.

## Pagamentos e storage

Ver docs de provedores. `/payments/checkout`, `/webhooks/stripe`, `/webhooks/asaas`, `/auth/login`, `/auth/callback`, `/auth/logout` implementados em `provider-routes.ts`. Nenhum retorno do browser concede compra. Webhooks validam credenciais/assinaturas e estado canônico; licença e ledger persistem na mesma transação idempotente.

## Limites e pendências concretas

A matriz de requisitos é a autoridade de completude. Estes endpoints não equivalem à totalidade da V1. Leitura PDF/offline cifrado, anexos/quotas de upload, convites de comestre, editor de layout/template, calendário completo, busca textual avançada, presença/amigos, notificações, métricas editoriais, política econômica de pontos, frete/cotação, reembolso e saques, exclusão/retenção de conta exigem trabalho adicional. Versões de livro não podem ser marcadas validadas por cliente comum. Solicitação print não comprova compra física nem inicia fornecedor. Nenhum stub de provedor indica sucesso.
